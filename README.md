# सार्थी ट्रांसपोर्ट (Saathi Transport)

An all-India on-demand truck/tempo booking marketplace — customers post loads, drivers bid, and admins run the platform.

Built with React + Vite + Tailwind CSS + lucide-react.

## Apps included

- **Customer** — post a load (now or in advance), review driver bids, track a trip live, rate drivers, download invoices.
- **Driver** — go online/offline, quote fares on open loads, complete KYC, run a loading timer with OTP pickup verification, manage wallet/bonus/withdrawals.
- **Admin** — live fleet dashboard, KYC approval desk, driver list/blacklist, commission & wallet settings, finance reports, notifications, SOS/emergency alerts.

The root `App` component starts in a demo "role switcher" mode so all three apps are reachable from one screen.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL. To build for production:

```bash
npm run build
npm run preview
```
